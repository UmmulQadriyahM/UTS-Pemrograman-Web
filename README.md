Template website yang saya buat adalah Website Sekolah UPTD SMPN 17 Pukkiseng yang berfungsi sebagai sistem sederhana untuk manajemen data siswa.

Website ini memiliki beberapa halaman utama, yaitu landing page, login, dashboard admin, halaman data siswa, dan form input data siswa. 
Pada halaman data siswa ditampilkan informasi dalam bentuk tabel, sedangkan penambahan data dilakukan melalui form yang telah disediakan.

Template ini dirancang untuk memudahkan administrator dalam mengelola data siswa secara terstruktur, 
serta dilengkapi dengan navigasi yang terhubung antar halaman dan tampilan yang sederhana, rapi, dan mudah digunakan.
